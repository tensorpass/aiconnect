# @tensorpass/aiconnect-design

The design tokens and marks shared by the AI Connect connect window, the AI Wallet extension and https://tensorpass.app: `tokens.css`, the TensorPass mark (`brand-mark`), the providers' marks (`provider-marks`), the key card colours (`card-tints`) and the room meter's colours (`room-color`). `@tensorpass/aiconnect-react` installs it, so a site does not add it by hand.
