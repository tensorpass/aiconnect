# @tensorpass/aiconnect-react

The React components and hooks of AI Connect: the connect window, a chat with your site's tools, and the interface modules (side panel, popup, inline chat, search bar, full page). Each visitor answers with their own AI account through the AI Wallet browser extension, or signs in with OpenRouter or the TensorPass plan without it.

```bash
npm install @tensorpass/aiconnect @tensorpass/aiconnect-react
```

```tsx
import { AiConnectProvider, AiChatPanel } from '@tensorpass/aiconnect-react';
import '@tensorpass/aiconnect-react/styles.css';
```

It needs React 19 or later. Docs: https://tensorpass.app/docs. React quickstart: https://tensorpass.app/docs/quickstart/react. Next.js quickstart: https://tensorpass.app/docs/quickstart/nextjs.
